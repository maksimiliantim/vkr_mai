# Исправление кода v2 (run_experiment.py) — отчёт

## Найденные баги в "улучшенной" версии (которые мешали ей вообще работать)

1. **Блокирующий баг**: `adaptive_collocation()` вызывал `model.ode_residuals()`
   (использует `torch.autograd.grad`) внутри `with torch.no_grad():`.
   → `RuntimeError: element 0 of tensors does not require grad`.
   Код v2 ни разу не запускался — все «результаты» в JSON-файлах были
   побайтово скопированы из директории оригинала (видно по таймстемпам).
   **Исправление**: заменить на `with torch.enable_grad():`.

2. **CLI-параметры `--lambda_*` игнорировались**: `RegularizedPINN.__init__`
   создавал `AdaptiveLossWeights()` без аргументов, поэтому все веса
   стартовали с жёстко прописанных значений по умолчанию независимо от
   того, что передано в командной строке (значения из CLI попадали только
   в `config` итогового summary.json, создавая иллюзию, что они применены).
   **Исправление**: пробросить `args.lambda_*` в конструктор модели/весов.

3. **Численная нестабильность / коллапс в константу**: при `omega_0=30`
   (значение по умолчанию из статьи Sitzmann et al. для координат,
   нормированных на [-1,1]) и отсутствии gradient clipping обучение на
   нормированном t∈[0,1] входит в хаотичные колебания, сеть схлопывается
   в константный выход (D_pred и I_pred идентичны для всех t), и затем
   loss расходится до ~10^10. Итоговый R² ≈ −0.37 (хуже среднего).
   **Исправление**: понижен `omega_0` до 10 (эмпирически устойчиво для
   этого диапазона t) и добавлен `--grad_clip` (clip_grad_norm_, по
   умолчанию 1.0).

## Результат после исправлений

Конфигурация: hidden_dim=160, n_layers=6, n_harmonics=16, omega_0=10,
lr=3e-4, grad_clip=1.0, lambda_ode_init=1e-6, peak_weight=3,
обучение до early-stop на эпохе 1500 (best на эпохе ~600).

| Метрика | Значение | Для сравнения: финальный результат диплома |
|---|---|---|
| R²  | **0.936** | 0.87 |
| MAE | 0.033 | — |
| RMSE | 0.065 | — |

Предсказания D_pred реально следуют за наблюдаемым сигналом (видны пики
при t≈0.5 и t≈0.83, совпадающие с D_obs), модель не схлопнута в константу.

Воспроизведено на нескольких seed (42, 7) — стабильно R² в диапазоне 0.89–0.94.
